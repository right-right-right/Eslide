## 概述

一键编辑AI生成的HTML/SVG幻灯片中的文字，就像编辑PPT一样简单

现在很多都使用AI来生成幻灯片，做出来之后修改比较麻烦，要么是通过和AI对话帮助修改，要么就是自己去html源码里面去找相应的内容，于是我开发了这个编辑网页幻灯片的工具，帮助大家提升效率。

## ✨ 核心功能

**即点即改，告别复制粘贴**
- 无需打开开发者工具，无需复制代码
- 直接点击页面上的文字即可编辑，就像编辑本地文档一样自然
- 支持 HTML 文本和 SVG 图形中的文字

**智能格式工具栏**
- 加粗、斜体、下划线、删除线
- 调整字体颜色和大小
- 常用格式一步到位

**编辑历史记录**
- 撤销/重做功能，误操作可轻松回退
- 支持全部还原到原始状态
- 清晰的修改标记，重要改动不遗漏

**多种导出方式**
- 导出为 HTML 文件，随时保存修改
- 支持保存到原始文件
- 智能清理插件痕迹，导出版本纯净可用

## 🎯 适用场景

- **AI 幻灯片编辑**：ChatGPT、Claude 等 AI 工具生成的演示文稿，一键修改文字内容
- **网页内容微调**：临时需要修改网页上的文字，无需找原开发者
- **SVG 文字修改**：直接编辑 SVG 图形中的文字，无需专业设计软件
- **快速原型修改**：产品经理、设计师快速验证页面文案效果

## 🔒 安全与隐私

- 仅在您主动点击图标激活编辑模式后才运行
- 不会在后台收集任何数据
- 不会修改您未授权的网页内容
- 编辑记录仅保存在本地 sessionStorage 中

## 📌 使用方法

1. 安装插件后，点击浏览器工具栏中的插件图标
2. 进入编辑模式（页面顶部会显示编辑工具栏）
3. 点击任意可编辑的文字，直接进行修改
4. 使用工具栏调整格式或撤销操作
5. 编辑完成后，导出修改后的 HTML 文件

## ⚠️ 注意事项

- 部分网页可能禁用了文字编辑功能（受 CSP 安全策略限制）
- 仅编辑可见的可编辑元素
- 建议在重要修改前先导出备份
